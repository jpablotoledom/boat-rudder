%s

The 13 color variables from the project's Figma file, plus a separate "Generic links" trio added later. Applies to every epoch with a color model (1, 2 and 3) - epoch 3 gets these as CSS variables; epoch 1/2 (no CSS custom properties there) get a subset substituted straight into HTML attributes. Epoch -1/0 have no color model, nothing to apply here. Background colors also carry an opacity slider next to the picker (100%% = opaque) - browsers' native color picker has no alpha channel of its own, so this pairs a slider with a live preview swatch instead; opacity only has any visible effect in epoch 3, since epoch 1/2 have no alpha-transparency concept. Every color picker also offers the 16-color VGA palette alongside the free picker - on a real indexed-color (e.g. 8-bit) display, a color outside those 16 renders dithered (a pixel pattern) rather than solid; the "Body background (epoch 1 override)" field lets that one value differ from the shared Background above for exactly that reason.

Generic links color

Ordinary links inside page content - a paragraph, an image caption, anything that isn't the nav bar or a dedicated "link"/"gallery" block (those keep their own color). Separate from the menu colors above, so one can change without moving the other. Link/Visited/Active apply to epoch 1/2/3 - HTML's link/vlink/alink body attributes predate CSS and every epoch-1-era browser honors them too; Hover applies to epoch 2/3 (CSS1's a:hover, which epoch 2's real browsers - Netscape 4 and up - already support), but not epoch 1, which predates CSS entirely.

Table colors

The "table" content block's own colors, independent of every other section here - Header/Line/Row 1/Row 2 apply to epoch 2 and 3. Row 1 and Row 2 alternate by each content row's own position (the header row, if any, isn't counted), giving a striped look with no per-row choice to make; Line is the border between cells (epoch 3) / the table's outer background, which shows through as the grid line since cells sit 1px apart (epoch 2).

Code colors

The "code" content block's syntax highlighting (epoch 2 and 3). Keyword also colors function calls; Tag also colors HTML attributes and CSS property names, and covers C's #include-style directives and PHP's <?php markers.
