Translation

Adds a Translate button to the entry editor that fills the empty fields of the other languages from the one being edited. Azure AI Translator is called by the server: create a Translator resource in the Azure portal (the F0 tier is free, 2 million characters a month) and copy its key and its Location/Region (empty for a global resource). The key is never shown again - leave the field empty to keep it. A translator on this computer is a LibreTranslate-compatible server (POST /translate) running where the editor is: the browser calls it directly, so the site never needs to reach it.
