Site settings

Boat Rudder %4$s · Check for updates

%1$s

Site name

Shown in every page title, and wherever a theme prints the site's name (logo text, footer, alt texts).

Home page

Removes the "Latest Blog Posts" list from the home page in every epoch. The blog itself stays at /blog.

Maintenance mode

While it is on, every visitor gets the home page with this page's content in place of the home content, and no menu items or blog list, wherever they go on the site (home, pages, blog). Only Administrators can sign in, and only a signed-in Administrator sees the real site. Drafts can be chosen too.

%8$s

Favicon

Saved as favicon2.ico and favicon3.ico in the site root; without one, each epoch keeps its theme's icon.
